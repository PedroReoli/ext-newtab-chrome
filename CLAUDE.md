# AGENTS.md — Diretrizes Reoli (Governança & Business OS)

> Este repositório utiliza a suíte unificada **Reoli** (ReoliCode + ReoliOS).

## 🛠️ ReoliCode — Governança & Regras de Código
1. **Fonte de Verdade**: Consulte a pasta `.rules/` para acessar as regras de arquitetura, fundação, governança e workflow.
2. **Precedência**: Leia `.rules/README.md` para entender a hierarquia das regras.

## 🚀 ReoliOS — Sistema Operacional do Negócio
1. **Contexto & Memória**: Consulte a pasta `reolios/sistema/` (`memoria/`, `identidade/`, `scripts/`) para entender o negócio, produtos e preferências.
2. **Skills Operacionais**: Consulte a pasta `.claude/skills/` para acessar as +75 skills de dev, automação, vendas, copy, autoridade e gestão.
3. **Dashboard Web**: O usuário pode executar `reoli ui` no terminal para visualizar o painel web self-hosted.
